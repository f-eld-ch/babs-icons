# @f-eld-ch/babs-svg

Raw SVG source files and a structured index for the BABS civil-protection icon set. This package is the data layer consumed by the pipeline that generates `babs-core`, `babs-react`, and `babs-sprites`. Import it in tooling — custom renderers, server-side processors, non-JS consumers — not in browser application code.

## What's in the package

```
index.json          hierarchical index — categories, groups, icons
svg/                flat SVG files, one per distinct graphic (deduplicated)
de/                 per-language symlinks → svg/ entries
fr/
it/
```

### index.json schema

```json
{
  "categories": [
    {
      "number": "1",
      "name": { "de": "…", "fr": "…", "it": "…" },
      "subcategories": [
        {
          "number": "11",
          "name": { "de": "…", "fr": "…", "it": "…" },
          "symbols": [
            {
              "id": "1101",
              "identical": true,
              "label": { "de": "Beschaedigung", "fr": "Degat", "it": "Danneggiamento" },
              "files": {
                "de": { "lang": "de/1101-Beschaedigung.svg", "svg": "svg/1101-Beschaedigung.svg" },
                "fr": { "lang": "fr/1101-Beschaedigung.svg", "svg": "svg/1101-Beschaedigung.svg" },
                "it": { "lang": "it/1101-Beschaedigung.svg", "svg": "svg/1101-Beschaedigung.svg" }
              }
            }
          ]
        }
      ]
    }
  ]
}
```

`files[lang].lang` is the per-language symlink path; `files[lang].svg` is the actual file in `svg/`. For identical icons all three `svg` paths resolve to the same file. For divergent icons they point to distinct files.

## When to use this

- Building a custom renderer that reads SVG content directly
- Server-side processing (rasterisation, optimisation, format conversion)
- Non-JavaScript consumers that need raw SVG files (Python scripts, CI tooling)
- Generating your own metadata format from the structured index

For application use, prefer `@f-eld-ch/babs-core` (metadata and queries) or `@f-eld-ch/babs-react` (React components).

## Importing the index

```ts
import index from "@f-eld-ch/babs-svg/index.json" assert { type: "json" };

for (const category of index.categories) {
  for (const sub of category.subcategories ?? []) {
    for (const symbol of sub.symbols) {
      console.log(symbol.id, symbol.label.de);
    }
  }
}
```

Node 18+ and TypeScript 5+ support `assert { type: "json" }`. With `"resolveJsonModule": true` in `tsconfig.json` the assert clause can be omitted.

## Direct SVG file access

```ts
import { readFileSync } from "node:fs";
import { createRequire } from "node:module";

const require = createRequire(import.meta.url);
const pkgDir = require.resolve("@f-eld-ch/babs-svg/package.json")
  .replace("/package.json", "");

const svgContent = readFileSync(`${pkgDir}/svg/1101-Beschaedigung.svg`, "utf8");
```

Paths in `index.json` are relative to the package root. Join them against `pkgDir` to get absolute paths.

## Note

`packages/svg/` is generated by `yarn icons:flatten` from the upstream sources in `sources/`. Do not edit files in `svg/`, `de/`, `fr/`, or `it/` by hand — they will be overwritten on the next pipeline run.
